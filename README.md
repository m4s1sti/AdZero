### AdZero

A minimalist, high-performance Chrome extension built with Manifest V3 to block network-level tracking and eliminate YouTube/web ads in real-time.

### Features
- **Manifest V3**: Modern, secure Chrome extension architecture.
- **Network Filtering**: Blocks ad and tracker requests via `declarativeNetRequest`.
- **YouTube Optimizer**: Automatically skips video ads and accelerates playback.
- **DOM Cleaner**: Removes banner elements instantly.
- **Popup GUI**: Simple toggle switch and live stats counter.

### Tech Stack
- JavaScript, HTML5, CSS3
- Chrome Extension APIs (`storage`, `scripting`, `declarativeNetRequest`)

### Installation
1. Open `chrome://extensions/` in Google Chrome.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** and select this directory.
